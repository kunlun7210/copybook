# 我的字帖

个人英语单词字帖编辑器。输入单词、音标、中文和例句，预览四线格，导入词表并打印或保存 PDF。

## 使用

每行一个词，按 `单词|音标|中文|英文例句|中文例句` 排列。点击“生成字帖”，再打开“打印 / 保存PDF”。打印会打开独立页面，请在该页面点击打印按钮。选择与字帖一致的纸张、100% 缩放；关闭浏览器页眉页脚可避免附加网址。

“保存”内可下载 EZT 存档或打开本设备存档。设备间使用下载的 EZT 文件传递内容；不同浏览器的本地存档不自动同步。页面部署不上传字帖内容。

## 开发

Node.js 24，运行 `npm ci`。原 Sites 开发入口为 `npm run dev`；GitHub Pages 构建使用 `npm run build:pages`，输出 `dist-pages/`，部署由 GitHub Actions 完成。静态页面兼容仓库子路径，字体与导入组件随站点提供。
